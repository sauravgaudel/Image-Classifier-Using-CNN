#  Dog vs Cat Image Classifier

A deep learning project that uses a **Convolutional Neural Network (CNN)** to classify images as either a **Dog** or a **Cat**.

##  Tech Stack

- Python
- TensorFlow / Keras
- CNN
- FastAPI
- HTML, CSS, JavaScript
- Jupyter Notebook
